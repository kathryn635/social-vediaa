# Social-Vediaa

Социальная сеть  на React + Express + SQLite.

 Как запустить

```bash
# Терминал 1 — сервер
cd api
npm install
npm start

# Терминал 2 — клиент
cd client
npm install
npm start
Открыть http://localhost:3000, зарегистрироваться и пользоваться.
